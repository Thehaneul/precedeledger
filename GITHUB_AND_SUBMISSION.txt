tasks and two participants. The creator supplies before/after rules. Validators
independently interpret their meaning; deterministic code builds the dependency
graph and blocks cycles. The partner accepts the exact saved plan hash. Assigned
wallets can then report task completion only when all declared prerequisites have
completion receipts. Original rules, decisions and receipts remain inspectable.
